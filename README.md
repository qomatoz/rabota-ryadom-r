# Обновление «Работа рядом»: мульти-источниковый поиск

## Источники
- **Avito** — публичные результаты Avito, попавшие в поисковый индекс Bing. Это не полный поиск по Avito: открытого API вакансий для соискателей нет.
- **Telegram** — публичные посты, попавшие в поисковый индекс, и последние публикации каналов, перечисленных в `TELEGRAM_CHANNELS`. Закрытые чаты и весь Telegram целиком недоступны.
- **ВКонтакте** — публичные индексированные посты; дополнительно официальный VK API при наличии токена.
- **SuperJob** — официальный API при наличии ключа приложения.
- HH.ru временно не используется: API в текущем окружении отвечает 403.

## Твои фильтры
Кунгур — любой график. Пермь — только суточные смены. Явные упоминания ТК РФ, ГПХ, самозанятости и официального трудоустройства исключаются. `Подтверждено` означает, что в объявлении одновременно прямо сказано «без оформления» и указана оплата на руки/наличными/ежедневно. Остальные подходящие объявления получают статус `Нужно уточнить`. Отсутствие упоминания договора само по себе не доказывает неофициальную работу.

## Бесплатные ключи
В репозитории GitHub: **Settings → Secrets and variables → Actions**.
В Secrets добавь:
- `SUPERJOB_APP_ID` — Secret key приложения SuperJob (после регистрации приложения в кабинете разработчика).
- `VK_ACCESS_TOKEN` — токен VK API с разрешением на поиск публичных записей.

В Variables добавь:
- `TELEGRAM_CHANNELS` — публичные Telegram-каналы через запятую, без `@`.

Не присылай токены в чат и не добавляй их в файлы проекта. Без ключа соответствующий источник будет пропущен и появится предупреждение в `data/vacancies.json`.

## Установка
Распакуй архив. В GitHub-репозитории `qomatoz/rabota-ryadom-r` выбери **Add file → Upload files** и перетащи содержимое архива (не сам ZIP), сохраняя папку `.github/workflows`. Подтверди замену `fetch_vacancies.py`, `requirements.txt`, `README.md`, workflow; добавь новый `sources.py`. Нажми **Commit changes**, затем **Actions → Search vacancies → Run workflow**.

Расписание GitHub Actions может задерживаться. Сборщик не обходит CAPTCHA, авторизацию и ограничения площадок и не гарантирует полноту поиска. Если источник недоступен, ошибка будет показана отдельно, а не выдана за отсутствие вакансий.
